Ancient Book — Full Flow

00 — Gameplay

Game screen with diary closed. Top bar with inventory and DIARY button. LucasArts verb bar at bottom. Kabar scenario.

Hover state with gold border glow. Tooltip shows "Open diary (D)" shortcut.

02 — Notification

Badge with count (2). Temporary popup "Diary updated" with new entry preview. Pulsing animation.

03 — Opening Transition

Book partially open, darkened background. Loading bar animation ~0.5s.

04 — Tab: Story

Left page: motion comic (2/4) with controls. Right page: narrative text for Chapter III with scrollbar.

05 — Tab: Gallery

Left: selected image. Right: 3x3 thumbnail grid (4 of 8 unlocked). Progress bar.

06 — Tab: Characters

Left: Canus portrait with relationship, role, first encounter, background. Right: character card list.

07 — Tab: Places

Left: stylized Kabar map with 4 locations, compass rose, legend. Right: handwritten location notes.

08 — Tab: Clues

09 — Closing Transition

Reverse of opening. Book closing animation, background brightening.

10 — Chapter Switch

Navigating from Chapter III to Chapter II. Different content, section 1 of 4.

11 — Locked Chapter

Chapter IV locked. Large padlock, requirements to unlock, 60% progress bar, cryptic teaser.

Manuscript v2 — Full Flow

Refined version with handwritten aesthetic. Ink stains, fabric bookmarks, hand-drawn maps. No modern UI elements. 8 screens.

01 — Story

Ancient manuscript style (500 BC). Handwritten text, margin annotations, ink stains. Fabric bookmarks (brown/green/purple).

02 — Characters

Left: large Canus portrait with handwritten description. Right: rough sketches of Jaad, Merchant, mysterious figure.

03 — Places

Hand-drawn map with irregular paths, dashed streets. Location symbols: ✓ visited, ! current, ? to explore. Compass rose.

04 — Clues

Left: 3 key clues with sketches (Cephalopod statuette, Scroll, Arcane symbol). Right: connection diagram (Father → Statuette → Machine/Yog-Sothoth?).

05 — Button States

4 states: Normal, Hover, New annotation, Pressed. Quill pen as notification indicator. Variants: red seal, ribbons, glow.

06 — Opening Animation

4-frame timeline (600ms): Closed → Cover lifts → Semi-open → Fully open. Timing markers, ease-out easing, page rustle sound.

Animation Spec

07 — Chapter Index

Left: chapter list (I-II completed, III current in red, IV-V locked). Right: Chapter III preview with mini-map, progress, "Read chapter" button.

08 — Complete Flow Map

Full flow: Gameplay → Button states → Opening → Story → Sections → Chapter index → Closing. Design principles: no modern elements, handwritten, physical navigation.
